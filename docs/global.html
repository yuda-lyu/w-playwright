getChromiumLaunchOptions(optopt) → {Object}

Description:

  • 取得合併後之Chromium啟動選項(新物件; 供檢視與診斷); 永不拋錯

    啟動請一律用launchChromium、launchChromiumPersistent: 環境檢查(E_ENV)、版本檢查(E_PW_VERSION)與登入守門只在兩個啟動入口執行, 自行以本函數之結果呼叫playwright-core不在本套件之保證內

    合併規則: 命令列恰一個--disable-features(Playwright預設＋AutofillAiWalletPrivatePasses＋呼叫端自給, 置於呼叫端args之末), 並以ignoreDefaultArgs去掉Playwright預設之一串; 呼叫端之--disable-features、--enable-features一切變體(大小寫、單一連字號、無值)皆被吸收; 呼叫端以--enable-features啟用守門功能或同時停用之功能者剔除(原則3; 呼叫端停用Playwright預設enable之功能時預設enable亦剔除); args任一元素無效(非字串、頭尾空白〔含NEL〕、非-開頭、--、single-argument、控制字元〔C0、DEL、C1〕、功能項非ASCII語法、元素數逾10000)即整個args視為[](守門照加, 呼叫端其餘參數一併捨棄) 輸出恆含channel、executablePath鍵(未給時為undefined, 以蓋過Playwright之全域預設啟動選項)

    依呼叫時之環境變數PLAYWRIGHT_LEGACY_SCREENSHOT決定Playwright預設之enable, 故非純函數

(async) launchChromium(optopt) → {Promise}

Description:

  • 以Playwright啟動Chromium系瀏覽器(經本套件之合併參數; 唯一之非持久啟動入口)

    順序: 快照opt → 環境檢查(PWDEBUG為inspector模式、SELENIUM_REMOTE_URL有值即E_ENV) → playwright-core實裝版本≠內附表即E_PW_VERSION → 登入守門(環境變數W_PLAYWRIGHT_LOGON_GUARD開啟且種類非headless shell時) → 合併(getChromiumLaunchOptions之同一實作) → chromium.launch(或setBrowserTypeForTest之替身) → 受管瀏覽器缺檔時: autoInstall為true則安裝一次再啟動一次, 否則E_BROWSER_MISSING

    失敗一律reject固定詞彙之Error並帶code(E_ENV、E_PW_VERSION、E_LOGON_GUARD、E_BROWSER_MISSING、E_LAUNCH_TIMEOUT、E_LAUNCH、E_INSTALL); Playwright之原錯誤(含完整命令列)不附於對外錯誤, 只交opt.funLog('launch-error', { fn, code }, 原錯誤)

Source:
  • launchChromium.mjs, line 36

import wpw from 'w-playwright'

setBrowserTypeForTest(fake) → {function}

Description:

  • 測試接縫: 以替身取代本套件所呼叫之BrowserType, 回傳還原函數; 不對外提供原始BrowserType

    替身收到的是合併後之選項(與真啟動相同, 含守門)與next:

    • fake.launch(mergedOpt, next): next()以同一份合併後選項呼叫真chromium.launch; next(o)對o重走完整流程(環境、版本、登入守門、合併)後呼叫真chromium.launch
    • fake.launchPersistentContext(userDataDir, mergedOpt, next): 同上, 對應真chromium.launchPersistentContext(未提供此方法時, launchChromiumPersistent以E_LAUNCH失敗) 替身之拋錯依真啟動之規則轉為固定詞彙錯誤(訊息含"Executable doesn't exist at"者視為受管瀏覽器缺檔)

    同一行程內使用端之src與測試取同一個主檔模組, 替換對兩者同時有效(依賴樹有兩份本套件時只作用於呼叫者那一份, 使用端之接線測試須斷言替身確被呼叫); 多次設定時以最後設定且未還原者生效; 還原函數只移除自己這一份(不論還原順序), 重複呼叫無作用; 替身之方法以原fake物件為this呼叫
